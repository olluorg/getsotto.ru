React с TypeScript

Основа с Junior

Типизация props, событий, хуков и контекста.

type ButtonProps = {
  variant?: "primary" | "ghost";
  onClick: (e: React.MouseEvent<HTMLButtonElement>) => void;
  children: React.ReactNode;
} & React.ComponentProps<"button">;

function Button({ variant = "primary", ...rest }: ButtonProps) {
  return <button className={variant} {...rest} />;
}

const [user, setUser] = useState<User | null>(null);

Что важно знать

  • Props — через type или interface; React.FC не обязателен.
  • React.ReactNode для children, React.ComponentProps<"input"> — унаследовать атрибуты нативного элемента.
  • Состояние, которое начинается с null, — явный тип в useState.
  • Типы событий: React.ChangeEvent<HTMLInputElement>, React.FormEvent.
  • Контекст без значения по умолчанию — свой хук с проверкой, что провайдер есть.
  • Дженерик-компоненты: function List<T>({ items, render }: …).

Критерии освоения

Junior ≈ 4 ч

  • Типизирует props, состояние и события в React-компонентах

Практика. Перевести React-проект на TypeScript в режиме strict.

Middle ≈ 4 ч

  • Пишет дженерик-компоненты и типизирует контекст с проверкой провайдера

Практика. Сделать типизированный дженерик-компонент таблицы с колонками и сортировкой.
