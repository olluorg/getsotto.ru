Java Memory Model и атомарность

Основа с Middle

happens-before, volatile, атомарные классы и CAS.

Что важно знать

  • Без синхронизации поток может не увидеть запись другого потока.
  • happens-before: запуск потока, запись в volatile, освобождение монитора.
  • volatile даёт видимость, но не атомарность i++.
  • CAS — основа атомарных классов; LongAdder под высокой конкуренцией.

  • Что делает класс AtomicInteger? Junior

    AtomicInteger выполняет операции вроде инкремента атомарно без блокировок — на аппаратной инструкции CAS (сравнение с обменом).

  • Что гарантирует ключевое слово volatile для переменной? Middle

    volatile даёт видимость (запись сразу видна другим потокам) и запрет переупорядочивания вокруг обращения, но не атомарность: count++ на volatile-поле всё равно теряет обновления.

  • Один поток в цикле читает обычное поле-флаг, другой его меняет, но цикл не завершается. Почему? Junior
