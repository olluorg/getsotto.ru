Data Scientist: карта развития

Data scientist превращает данные в решения: строит модели, проверяет гипотезы экспериментами и доводит результат до бизнеса. Путь сверху вниз — порядок изучения: база и математика, Python и SQL для данных, статистика и эксперименты, основы машинного обучения и модели, прикладные задачи, глубокое обучение, продуктовая аналитика и модели в продакшене.
