Командная строка

Основа

Навигация, файлы, процессы, переменные окружения и пайпы — работа в терминале без страха.

Терминал нужен каждый день: запустить проект, поставить зависимости, работать с Git, зайти на сервер, посмотреть логи, быстро найти что-то в сотне файлов.

cd ~/projects/shop && ls -la          # перейти и посмотреть файлы
grep -rn "TODO" src/ | head            # найти по содержимому
cat app.log | grep ERROR | wc -l       # пайп: посчитать ошибки
export API_URL=http://localhost:8080   # переменная окружения
ps aux | grep node; kill 12345         # процессы

Что важно знать

  • Пути: абсолютные и относительные, ~, . и ...
  • Файлы: ls, cp, mv, rm (без корзины!), mkdir -p, cat, less, head, tail -f.
  • Поиск: grep, find; современные rg и fd быстрее.
  • Пайпы | и перенаправление >, >>, 2>&1.
  • Переменные окружения и PATH — почему «команда не найдена».
  • Права и sudo, chmod +x для скриптов.
  • Процессы: ps, top, kill, Ctrl+C.
  • ssh для входа на сервер, curl для запросов к API.
  • На Windows — WSL: большая часть инструментов разработки рассчитана на Unix-окружение.

Вопросы с собеседований

  • Какими командами вы диагностируете проблему на Linux-сервере? Middle

    Порядок: жив ли процесс (systemctl status, ps) → логи (journalctl, файлы приложения) → ресурсы (top, free, df, iostat) → сеть (ss -tlnp — слушает ли порт, curl localhost, dig) →…

  • Как устроены права доступа к файлам в Linux? Junior

    У файла есть владелец, группа и три набора прав — для владельца, группы и остальных: чтение (r = 4), запись (w = 2), выполнение (x = 1). chmod 755 — владелец rwx (7), группа и…
