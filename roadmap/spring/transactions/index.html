Транзакции в Spring

Основа с Junior

@Transactional, распространение, изоляция, откат и типичные ловушки.

Что важно знать

  • Транзакция работает через прокси — только для внешних вызовов публичных методов.
  • По умолчанию откат только при unchecked-исключениях.
  • readOnly = true — подсказка для оптимизаций.
  • Внешний HTTP-вызов внутри транзакции держит соединение и блокировки.

Критерии освоения

Junior ≈ 4 ч

  • Использует @Transactional на сервисном слое для связанных изменений

Практика. Сделать оформление заказа с резервом товара в одной транзакции и тестом отката.

Middle ≈ 6 ч

  • Объясняет propagation REQUIRED и REQUIRES_NEW и откат при checked-исключениях
  • Находит причины, по которым транзакция не работает — самовызов, private, не тот менеджер
  • Не держит транзакцию во время внешних вызовов

Практика. Записать журнал аудита в отдельной транзакции REQUIRES_NEW так, чтобы он сохранялся при откате основной.

Вопросы с собеседований

  • Что происходит при выходе из метода с @Transactional, если исключений не было? Junior

    Успешный выход из метода — коммит (если метод начал транзакцию). Исключение по умолчанию откатывает только неконтролируемые (RuntimeException, Error); checked — коммит.

  • Как работает @Transactional и почему вызов метода внутри того же класса (self-invocation) может не открыть транзакцию? Middle

    @Transactional реализован прокси: вызов снаружи идёт через прокси, который открывает транзакцию и вызывает метод. Вызов this.other() внутри класса идёт мимо прокси — аннотация на…

  • Что делает propagation=REQUIRES_NEW и какой подводный камень с пулом соединений он несёт? Senior

    REQUIRES_NEW приостанавливает текущую транзакцию и открывает новую независимую — со своим соединением. На это время поток держит два соединения: при большом параллелизме пул…

  • При каком исключении @Transactional по умолчанию откатывает транзакцию? Middle

    По умолчанию откат — на RuntimeException и Error. На checked-исключения транзакция коммитится. Меняется через rollbackFor и noRollbackFor.
