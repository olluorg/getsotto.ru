Вопросы с собеседований

  • Для чего предназначен Spring Batch? Junior

    Пакетная обработка больших объёмов: импорт и выгрузка файлов, перерасчёты, рассылки — чтение, преобразование и запись порциями с сохранением прогресса и перезапуском с места сбоя.

  • Как устроена chunk-ориентированная обработка в Spring Batch и что она даёт? Middle

    Chunk — порция: прочитать N записей по одной, обработать, записать пачкой в одной транзакции. Память ограничена размером чанка, а после сбоя задание продолжается с последнего…

  • Что такое Spring Batch и из каких основных частей состоит batch job? Senior

    Spring Batch — фреймворк для пакетной обработки больших объёмов: Job состоит из Step, шаг обычно chunk-ориентированный — ItemReader → ItemProcessor → ItemWriter пачками с коммитом…

  • Когда полезен Spring Integration? Senior

    Spring Integration — реализация Enterprise Integration Patterns: сообщения проходят через каналы и конечные точки (маршрутизаторы, преобразователи, фильтры, разделители…

  • Какие основные backend-риски у GraphQL? Senior

    Клиент сам составляет запрос, поэтому риски на бэкенде: N+1 в резолверах, дорогие и глубокие запросы (DoS одним запросом), сложное кэширование (всё через POST на один URL)…
