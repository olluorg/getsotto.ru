Локальные и собственные модели

Полезно знать с Middle

Запуск открытых моделей — Ollama для разработки, vLLM для продакшена.

Открытую модель можно запустить у себя: на ноутбуке для разработки или на GPU-сервере в продакшене.

Что важно знать

  • Ollama, LM Studio — локальный запуск в одну команду, удобно для экспериментов и офлайн-разработки.
  • vLLM, SGLang, TGI — серверы для продакшена: непрерывная пакетная обработка, эффективный KV-кэш, API в формате OpenAI.
  • Память: модель на 8 млрд параметров в 16 битах занимает около 16 ГБ только весами, плюс KV-кэш под контексты.
  • Квантизация уменьшает память в 2–4 раза.
  • Свой сервер оправдан при больших объёмах, требованиях к данным или необходимости дообучения.

Критерии освоения

Middle ≈ 8 ч

  • Запускает открытую модель локально через Ollama и обращается к ней по OpenAI-совместимому API
  • Объясняет, сколько памяти нужно модели и как квантизация её уменьшает

Практика. Запустить локально модель на 7–8 млрд параметров, прогнать на ней свой набор из 50 примеров и сравнить с моделью по API.

Senior ≈ 8 ч

  • Разворачивает vLLM на GPU-сервере, измеряет пропускную способность и задержку под нагрузкой
  • Сравнивает стоимость своей модели и API при реальном профиле нагрузки

Практика. Развернуть vLLM, провести нагрузочный тест на 20 одновременных пользователей и посчитать стоимость миллиона токенов против API.
