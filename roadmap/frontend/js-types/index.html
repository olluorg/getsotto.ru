Типы, сравнение и копирование

Основа

Примитивы и объекты, приведение типов, == против ===, ссылки и копирование.

В JavaScript 7 примитивов — string, number, bigint, boolean, undefined, null, symbol — и объекты (включая массивы и функции). Примитивы копируются по значению, объекты — по ссылке.

typeof null            // "object" — историческая ошибка
0.1 + 0.2 === 0.3      // false — плавающая точка
[] == false            // true — приведение типов
const a = { n: 1 }; const b = a; b.n = 2; a.n  // 2 — одна ссылка

Что важно знать

  • === сравнивает без приведения типов — использовать всегда; == — только осознанно (x == null ловит и null, и undefined).
  • Ложные значения: false, 0, -0, 0n, "", null, undefined, NaN. NaN !== NaN, проверка — Number.isNaN.
  • ?? срабатывает только на null/undefined, || — на любое ложное.
  • Копирование: {...obj} и [...arr] — поверхностные, structuredClone(obj) — глубокое.
  • Методы массивов: map, filter, reduce возвращают новый массив, sort, reverse, splice меняют исходный (есть неизменяющие toSorted, toReversed, toSpliced).

  • Чем == отличается от === в JavaScript? Junior

    === — строгое сравнение: типы должны совпадать, без преобразований. == — нестрогое: перед сравнением приводит типы по запутанным правилам ("1" == 1, 0 == "", null == undefined …

  • Как скопировать объект в JavaScript и чем поверхностная копия отличается от глубокой? Junior

  • Какие методы массивов меняют исходный массив, а какие возвращают новый? Junior
