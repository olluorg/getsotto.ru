Области видимости и замыкания

Основа

var, let и const, всплытие, лексическое окружение и замыкания.

Замыкание — функция вместе с окружением, в котором она создана: она помнит переменные внешней функции даже после её завершения.

function counter() {
  let n = 0;
  return () => ++n;
}
const next = counter();
next(); next();   // 2 — n живёт в замыкании

Что важно знать

  • var — область видимости функции, всплывает со значением undefined; let/const — блочная область, до объявления — «временная мёртвая зона» (ReferenceError).
  • const запрещает переприсваивание, но не изменение объекта.
  • Классическая задача: цикл for (var i…) с setTimeout печатает одно и то же число; с let у каждой итерации своя переменная.
  • Где применяются замыкания: приватное состояние, фабрики функций, debounce и throttle, обработчики событий, хуки React.
  • Замыкание удерживает переменные в памяти — источник утечек, если держать ссылку на большие объекты в долгоживущем обработчике.

Вопросы с собеседований

  • Чем var отличается от let и const? Junior

    var — область видимости функции, поднимается (hoisting) со значением undefined, допускает повторное объявление. let и const — область видимости блока {}, до строки объявления …

  • Что такое замыкание в JavaScript и где оно применяется? Junior

    Замыкание — функция вместе с лексическим окружением, в котором она создана: она помнит переменные внешней функции даже после её завершения. Применение: приватное состояние…

  • Чем debounce отличается от throttle? Junior

    Debounce — вызвать функцию, только когда события прекратились на N мс: поиск по вводу, сохранение черновика, resize. Throttle — вызывать не чаще раза в N мс, пока события идут…
