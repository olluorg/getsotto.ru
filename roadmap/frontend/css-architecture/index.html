Организация стилей — БЭМ, CSS Modules, Tailwind

Основа с Junior

Как не утонуть в стилях большого проекта — соглашения об именах, изоляция и утилитарный подход.

Главная проблема CSS в большом проекте — глобальность: любое правило может задеть чужой компонент. Подходы решают её по-разному.

подходидеяцена
БЭМсоглашение об именах: card__title--activeдисциплина, длинные классы
CSS Modulesклассы автоматически уникальны для файланужна сборка
CSS-in-JS (styled-components, Emotion)стили в компоненте, динамика из пропсовцена в рантайме, сложности с SSR
Tailwindутилитарные классы прямо в разметкедлинная разметка, свой словарь

Что важно знать

  • Изоляция стилей компонента и общий слой токенов (цвета, отступы, шрифты) в переменных.
  • Для React-проектов сейчас чаще встречаются CSS Modules и Tailwind; CSS-in-JS с рантаймом уходит из-за серверных компонентов.
  • Препроцессоры (Sass) всё ещё распространены, но переменные, вложенность и @layer в чистом CSS закрывают большую часть задач.

Критерии освоения

Junior ≈ 4 ч

  • Применяет один подход к организации стилей последовательно — БЭМ, CSS Modules или Tailwind

Практика. Перевести стили учебного проекта на CSS Modules или Tailwind без глобальных конфликтов.

Middle ≈ 6 ч

  • Обосновывает выбор подхода к стилям для проекта с учётом SSR и команды
  • Выносит токены дизайна в переменные и поддерживает темы

Практика. Добавить тёмную тему на токенах в CSS-переменных без изменения компонентов.
