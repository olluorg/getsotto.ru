Снимок экрана

Держите правый Ctrl — sotto снимет экран и ответит с учётом того, что на нём. Ctrl+Alt+A — прочитать только выделенную область. По умолчанию текст со снимка читается на вашем компьютере и снимок никуда не уходит; в настройках можно отдавать его модели со зрением — она понимает и картинки.

Код

Win+A копирует код из окна в фокусе. Началась задача — окно кода откроется само: решение по шагам, этапы листаются Ctrl+Alt+← и Ctrl+Alt+→.

IntelliJ IDEA и браузер

  • Плагин для IntelliJ IDEA (2026.2 и новее): Settings → Plugins → ⚙ → Install Plugin from Disk, затем войдите в аккаунт в Settings → Tools → ghost. Плагин отдаёт открытую вкладку дословно, без снимка.
  • Расширение для Chrome, Edge и Яндекс Браузера: распакуйте, chrome://extensions → «Режим разработчика» → «Загрузить распакованное». Передаёт код из редактора на странице, условие и вывод тестов. Только читает: на странице ничего не меняет.
