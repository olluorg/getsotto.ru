При первом запуске на месте ленты подсказок открывается мастер. Любой шаг можно пропустить: всё то же самое есть в настройках.

1. Вход

Правила: sotto нельзя использовать там, где посторонняя помощь запрещена — на экзаменах, аттестациях, тестах. Записываете звук — предупредите собеседника. Затем вход через Яндекс ID или VK ID: первые 30 минут — бесплатно.

2. Звук

Скажите что-нибудь — дрогнет полоса «Слышу вас». Включите любое видео — дрогнет «Слышу собеседника». Подробнее — в статье «Звук».

3. Разговор

Для чего вам sotto — собеседование, учёба, звонок или доклад: от этого зависит, как модель отвечает. Язык разговора — русский или английский. И скрывать ли подсказки при демонстрации экрана: по умолчанию скрываются.

4. Начало

Клавиши, которые работают в любом окне, ссылка на это обучение и кнопка «Рассказать о себе».

Распознавание речи

Речь распознаётся на вашем компьютере моделью Whisper — около 2 ГБ, один раз. Загрузка начинается сама, как только открылся мастер; её ход виден внизу на каждом шаге. С видеокартой NVIDIA распознавание быстрее, без неё работает на процессоре.
