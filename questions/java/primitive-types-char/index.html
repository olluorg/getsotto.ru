Сколько в Java примитивных типов и что хранит char?

JuniorОсновы языка
Ещё спрашивают так:
  • Какие примитивные типы есть в Java?
  • Сколько байт занимает char?
  • Чем примитив отличается от обёртки?
Коротко

Примитивов восемь: byte, short, int, long, float, double, char, boolean; char — 16-битный беззнаковый, один UTF-16 code unit.

  • Целые 8/16/32/64 бита, float 32, double 64, размер boolean не задан спецификацией
  • Эмодзи и редкие символы — два char (суррогатная пара), length() считает char, а не символы

Подробно

Примитивы хранят значение напрямую, а не ссылку на объект:

ТипРазмерЧто хранит
byte8 битцелое −128..127
short16 битцелое
int32 битацелое, около ±2,1 млрд
long64 битацелое
float32 битачисло с плавающей точкой
double64 битачисло с плавающей точкой
char16 битбеззнаковый код UTF-16
booleanне заданtrue/false

char — не «символ» в человеческом смысле, а одна кодовая единица UTF-16. Символы вне базовой плоскости Unicode (эмодзи, часть иероглифов) занимают два char — суррогатную пару. Поэтому "😀".length() равно 2; настоящие символы считают через codePointCount.

Ещё о чём спрашивают: у каждого примитива есть обёртка (Integer, Character…) для коллекций и дженериков; целочисленное переполнение не бросает исключение (Integer.MAX_VALUE + 1 даёт Integer.MIN_VALUE) — для контроля есть Math.addExact; деньги не считают во float/double из-за ошибок округления — берут BigDecimal или копейки в long.

Что хотят услышать

  • Все восемь примитивов и их размеры.
  • char как 16-битный UTF-16 code unit и суррогатные пары.
  • Отличие примитивов от обёрток.
  • Переполнение и BigDecimal для денег — плюс.

Частые ошибки

  • Считать char способным вместить любой символ Unicode (вне BMP — суррогатная пара).
  • Называть String примитивом.
