Что лежит в основе ArrayList?

JuniorКоллекции
Ещё спрашивают так:
  • Как устроен ArrayList?
  • Какая сложность операций у ArrayList?
  • Как ArrayList увеличивает размер?
Коротко

В основе — массив, который при заполнении заменяется большим с копированием элементов (примерно в 1,5 раза).

  • get по индексу — O(1), add в конец — амортизированно O(1)
  • Вставка и удаление в середине — O(n): элементы сдвигаются

Сколько раз ArrayList копирует массив

Подробно

ArrayList хранит элементы во внутреннем массиве elementData. Размер списка (size) обычно меньше длины массива (ёмкости) — есть запас.

Из устройства следуют характеристики:

  • доступ по индексу — O(1): адрес вычисляется арифметически;
  • добавление в конец — обычно O(1). Когда массив заполнен, создаётся новый большего размера (в HotSpot — примерно в 1,5 раза) и элементы копируются. Копирование дорогое, но редкое, поэтому в среднем по серии операций добавление — амортизированное O(1);
  • вставка и удаление в середине — O(n): все элементы правее нужно сдвинуть;
  • поиск по значению (contains, indexOf) — O(n).

Практика: если размер известен, передать ёмкость в конструктор (new ArrayList<>(10_000)) — расширений не будет. Массив сам не уменьшается при удалении: для этого есть trimToSize().

ArrayList не потокобезопасен.

Что хотят услышать

  • Динамический массив и механизм расширения с копированием.
  • Сложность основных операций, амортизированное O(1) для add.
  • Совет про начальную ёмкость — плюс.

Частые ошибки

  • Ожидать дешёвого удаления из середины.
  • Путать внутреннее устройство со связным списком.
