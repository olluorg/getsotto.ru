Что произойдёт при выполнении: Integer x = null; int y = x;?

JuniorОсновы языка
Коротко

NullPointerException: int y = x компилируется в x.intValue(), а вызов метода на null — NPE. Обёртка может быть null, примитив — нет.

  • Типичный источник: map.get(key), поля сущностей Integer, результаты JDBC
  • Защита: getOrDefault, Objects.requireNonNullElse, примитив там, где «нет значения» бессмысленно
  • Сообщение NPE в Java 14+ подскажет: Cannot invoke "Integer.intValue()"

Подробно

int y = x компилируется в x.intValue(), а вызов метода на null даёт NullPointerException. Типичный источник — результаты, способные вернуть null (map.get(key)), присвоенные примитиву. Защита: использовать примитив там, где «отсутствие» бессмысленно; подставлять дефолт через getOrDefault / Objects.requireNonNullElse; для «значение может отсутствовать» возвращать Optional, а не nullable-обёртку.
