Как работает прототипное наследование и что такое class в JavaScript?

JuniorОсновы JavaScript
Ещё спрашивают так:
  • Что такое __proto__ и prototype?
Коротко

У каждого объекта есть ссылка на прототип; если свойства нет в объекте, оно ищется по цепочке прототипов. Методы хранятся в прототипе и разделяются всеми экземплярами. class — синтаксический сахар над конструктором и прототипом, с более строгими правилами.

  • F.prototype — прототип для объектов, созданных new F()
  • Object.getPrototypeOf(obj) — правильный способ получить прототип (__proto__ — устаревший)
  • extends настраивает цепочку, super вызывает метод родителя

А ещё Object.create(proto) — объект с заданным прототипом без конструктора

Так подсказку видит пользователь sotto на живом собеседовании — за пару секунд, пока вы думаете вслух.

Подробно

class Animal {
  constructor(name) { this.name = name; }
  speak() { return `${this.name} издаёт звук`; }
}
class Dog extends Animal {
  speak() { return `${super.speak()}: гав`; }
}
const d = new Dog("Рекс");
// d → Dog.prototype → Animal.prototype → Object.prototype → null

Поиск свойства: d.speak — нет в d, есть в Dog.prototype. d.toString — дошли до Object.prototype.

Что делает new: создаёт объект с прототипом F.prototype, вызывает конструктор с этим объектом в this, возвращает его.

Отличия class от функции-конструктора: нельзя вызвать без new, код класса в строгом режиме, методы неперечисляемые, есть #приватные поля и статические блоки.

Ловушка: изменение встроенных прототипов (Array.prototype.x = ...) ломает чужой код — так не делают.
