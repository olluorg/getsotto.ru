Когда полезен Spring Integration?

SeniorSpring Batch и IntegrationSpring
Ещё спрашивают так:
  • Что такое Enterprise Integration Patterns?
Коротко

Spring Integration — реализация Enterprise Integration Patterns: сообщения проходят через каналы и конечные точки (маршрутизаторы, преобразователи, фильтры, разделители, агрегаторы), адаптеры подключают внешние системы — файлы, FTP, почту, JMS, Kafka, HTTP.

  • Хорош для интеграционных конвейеров между разнородными системами
  • Java DSL: IntegrationFlow.from(...).transform(...).route(...).handle(...)
  • Для простой отправки в брокер избыточен — достаточно KafkaTemplate или Spring Cloud Stream

А ещё Альтернатива вне Spring — Apache Camel

Так подсказку видит пользователь sotto на живом собеседовании — за пару секунд, пока вы думаете вслух.

Подробно

EIP — каталог шаблонов интеграции (Хоп и Вулф): канал сообщений, маршрутизатор по содержимому, преобразователь, фильтр, разделитель, агрегатор, канал недоставленных, опрашивающий потребитель и другие.

Spring Integration реализует их как компоненты внутри приложения:

  • сообщение — заголовки и полезная нагрузка;
  • каналы — прямые (синхронный вызов), очереди, publish-subscribe;
  • конечные точки — transformer, filter, router, splitter, aggregator, service activator (вызов вашего метода);
  • адаптеры — входящие и исходящие для файлов, SFTP, почты, JDBC, JMS, AMQP, Kafka, HTTP, MQTT.

Пример задачи: забрать CSV с SFTP раз в 5 минут, разбить на строки, отфильтровать, преобразовать в события, сгруппировать по клиенту и отправить в Kafka, ошибочные — в отдельную папку.

Когда применять: интеграция с внешними и устаревшими системами, много протоколов и шагов преобразования. Когда не нужно: простое чтение и запись в один брокер — там Spring Kafka или Spring Cloud Stream проще; сложная потоковая обработка с состоянием — Kafka Streams или Flink.

Что хотят услышать

  • Что такое EIP.
  • Каналы, конечные точки, адаптеры.
  • Когда применять и когда избыточен.

Частые ошибки

  • Тянуть Spring Integration ради одной отправки в очередь.
