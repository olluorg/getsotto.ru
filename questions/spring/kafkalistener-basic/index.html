Что делает аннотация @KafkaListener?

JuniorSpring KafkaSpring KafkaKafka
Ещё спрашивают так:
  • Как читать сообщения Kafka в Spring?
Коротко

@KafkaListener(topics = "orders", groupId = "billing") объявляет обработчик: цикл poll(), десериализацию, вызов метода и коммит offset берёт на себя контейнер Spring Kafka.

  • Коммит — после обработки (по умолчанию после пачки)
  • Ошибки — DefaultErrorHandler: повторы, затем DLT
  • concurrency — число потребителей

А ещё Обработчик должен быть идемпотентным

Так подсказку видит пользователь sotto на живом собеседовании — за пару секунд, пока вы думаете вслух.

Подробно

За аннотацией стоит контейнер слушателя: он ведёт цикл опроса брокера, разбирает сообщение в нужный тип, вызывает ваш метод и фиксирует позицию чтения после успешной обработки. Благодаря этому в коде остаётся только полезная логика. Отправкой занимается отдельный компонент — шаблон для публикации. Важная деталь для понимания поведения при сбоях: если метод бросил исключение, позиция не сдвигается, и сообщение будет получено снова, поэтому обработка должна выдерживать повторы.
